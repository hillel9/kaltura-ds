Tokens — Spacing

4px base. --ds-space-N = N × 4px. Half steps use a dash (1-5 = 1.5 × 4 = 6px).
KEP UI (MUI) counts in 8px units: theme.spacing(n) = --ds-space-{2n}. So spacing(0.5) = --ds-space-1 (4px), spacing(1) = --ds-space-2 (8px), spacing(1.5) = --ds-space-3, spacing(2) = --ds-space-4, spacing(3) = --ds-space-6, spacing(4) = --ds-space-8. Same pixels, different counting.

Processing: add ds-btn-processing and aria-busy="true" while an action runs, or call DS.setProcessing(button, true) and DS.setProcessing(button, false). The label is hidden but the button keeps its width and color, a loader sized to the button replaces it, and clicks (mouse, Enter, Space) are ignored until it is removed. Don't add disabled at the same time.

Same names as KEP UI's SplitButton: an action button (ds-split-button-action), a menu toggle button (ds-split-button-menu-toggle) and a menu (ds-split-button-menu) of menu items. Both buttons are regular ds-btn buttons with the same size and color. The action button and menu items are plain buttons: listen for their click. Keyboard: Enter/Space on the toggle, or ArrowDown/ArrowUp on either button, opens the menu; arrows, Home and End move; Escape closes. To disable, put disabled on both buttons. While the action is processing (DS.setProcessing(actionBtn, true)) the menu can't open. Primary is the Figma design; secondary and danger follow KEP's color option.

Translucent

Matches the Figma Switch (Status, State, Size, Mode). States: off tone-3, on primary, disabled off tone-4, disabled on tone-3 (solid, no fade). Translucent (ds-switch-translucent) is for switches over images, video or dark surfaces (shown above on dark grey): off black 40%, on primary, disabled off black 20% with a faded handle, disabled on white 40%. Parts use KEP UI's names: the track (ds-switch-track), the thumb (ds-switch-thumb; Figma calls it Handle) and checked (aria-checked on the track, no state class needed). Old markup with ds-switch-handle and ds-switch-on / ds-switch-off still works. KEP calls translucent color="translucent".

  <span class="ds-switch-thumb"></span>
</button>

Same names as KEP UI's Breadcrumbs: each breadcrumb item (ds-breadcrumb-item) sits in an li, with a separator li (16px chevron-right) between items. Use <a href> for a link, <button> for a click action, <span> for plain text (no hover). Active (the current page): aria-current="page". Disabled: aria-disabled="true". Truncated: when the trail is wider than the nav, ds.js keeps the first item and as many last items as fit, and collapses the rest into a ... button ("Show more"); clicking it shows every item. Add data-collapse="none" to the nav to turn this off. 

<nav class="ds-breadcrumbs" aria-label="Breadcrumbs">
  <ol class="ds-breadcrumbs-ol">
    <li class="ds-breadcrumbs-li"><a class="ds-breadcrumb-item" href="/media">My Media</a></li>
    <li class="ds-breadcrumbs-separator" aria-hidden="true"><ds-icon name="chevron-right" size="16"></ds-icon></li>
    <li class="ds-breadcrumbs-li"><span class="ds-breadcrumb-item" aria-current="page">Onboarding</span></li>
  </ol>
</nav>

Modal

For forms and other user tasks. It is static: clicking outside it or pressing Escape does not close it, so people don't lose what they typed. It closes only with a Cancel button (any data-ds-close element) or DS.closeModal(). The title and footer stay in place; the body scrolls when the content is tall. Open with DS.openModal('id') or a data-ds-open="id" button. Focus is trapped while open and returns to the opener.
